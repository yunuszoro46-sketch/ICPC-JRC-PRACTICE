# ICPC JRC Team Codebook

A comprehensive collection of algorithms, data structures, and templates for competitive programming in ICPC and JRC competitions.

## Contents

### 1. **Data Structures**
- Union-Find (Disjoint Set Union)
- Segment Tree
- Fenwick Tree (Binary Indexed Tree)
- Graph Representations (Adjacency List, Matrix)
- Priority Queue / Heap

### 2. **Algorithms**
- **Sorting & Searching**
  - Binary Search
  - Merge Sort
  - Quick Sort

- **Graph Algorithms**
  - Dijkstra's Algorithm
  - BFS & DFS
  - Floyd-Warshall
  - Kruskal's & Prim's (MST)
  - Topological Sort
  - Strongly Connected Components (SCC)

- **Dynamic Programming**
  - Knapsack Problems
  - Longest Common Subsequence (LCS)
  - Longest Increasing Subsequence (LIS)
  - Matrix Chain Multiplication

- **Number Theory**
  - GCD & LCM
  - Prime Sieve (Sieve of Eratosthenes)
  - Modular Arithmetic
  - Fast Exponentiation

- **String Algorithms**
  - KMP (Knuth-Morris-Pratt)
  - Z-Algorithm
  - Hashing

- **Geometric Algorithms**
  - Convex Hull
  - Point in Polygon
  - Distance Calculations

### 3. **Common Templates**
- I/O Optimization
- Fast Read/Write
- Competitive Programming Boilerplate

---

## Usage

Each algorithm is implemented in a separate C++ file with:
- Clear explanations
- Time and space complexity analysis
- Example usage
- Edge cases handling

Good luck in your ICPC & JRC preparations! 🚀
