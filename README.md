# ICPC-JRC-PRACTICE

Competitive programming practice solutions, algorithmic templates, and problem sets for ICPC and JRC prep in C++.

Structure (ICPC-Preparation/):
- template.cpp: main contest template
- STL/: short STL snippets and helpers
- DataStructures/: implementations (segment tree, fenwick, dsu...)
- Algorithms/: algorithm templates (dijkstra, max flow...)
- Problems/: solved problems and practice files
- Notes/: math and algorithm notes

Usage
1. Compile a solution: g++ -std=gnu++17 -O2 ICPC-Preparation/template.cpp -o template
2. Copy snippets from the subfolders into contest submissions as needed.

Contributing
- Add well-tested, minimal templates.
- Include references or problem links in solution headers.
