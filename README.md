# ICPC & JRC Practice Repository

A comprehensive collection of competitive programming practice solutions, algorithmic templates, and problem sets for ICPC and JRC preparation in C++.

## Repository Structure

```
ICPC-JRC-PRACTICE/
├── ICPC-Preparation/           # Core preparation materials
│   ├── template.cpp            # Standard competitive programming template
│   ├── STL/                    # Standard Template Library utilities
│   ├── DataStructures/         # Common data structure implementations
│   ├── Algorithms/             # Algorithm implementations and patterns
│   ├── Problems/               # Practice problems
│   └── Notes/                  # Study notes and concepts
│
├── CSES/                       # CSES Problem Set Solutions
│   └── [Problem solutions organized by category]
│
├── CodeForce/                  # CodeForces Solutions
│   └── [Problem solutions by difficulty and contest]
│
└── README.md                   # This file
```

## Quick Start

1. **Review the Template**: Start with `ICPC-Preparation/template.cpp` for the standard setup
2. **Learn Data Structures**: Check `ICPC-Preparation/DataStructures/` for implementations
3. **Study Algorithms**: Explore `ICPC-Preparation/Algorithms/` for common algorithms
4. **Practice Problems**: Solve problems in `CSES/` and `CodeForce/` directories
5. **Take Notes**: Reference `ICPC-Preparation/Notes/` for key concepts

- ✅ Maintain clean, readable code with proper comments
